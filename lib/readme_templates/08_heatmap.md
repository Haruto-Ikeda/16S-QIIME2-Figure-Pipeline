# 08_heatmap: ヒートマップ (上位のタクソンの群平均)

上位のタクソンについて、群ごとの平均の相対存在量を色で示した図です。積み上げ棒 (07) では見にくい、少ないタクソンの違いも見られます。階級 (属など) ごとに 1 枚です。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `08_heatmap_<階級>.pdf` | 図 |

## 図の読み方

- **行:** タクソンです。07 の積み上げ棒と同じ選び方で、いちばん多いタクソンがいちばん上です。名前は右に書いてあります。
- **列:** 群です。下に、群の色の帯と名前があります。
- **マスの色:** その群の平均の相対存在量 (%) です。明るいほど多いことを示します。
- **色の目盛:** 0.1・1・10・100 (%) の、対数の目盛です。1 目盛で 10 倍の違いです。0.1% より少ないマス (0 も含みます) は、いちばん暗い色になります。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は検定に入れず、群の色の帯の中に `n < {{min_n}}` と書きます。色は付きます。

### 有意差の示し方

検定の方法によって、示し方が変わります。

| 検定 | マスの中 | 読み方 |
| --- | --- | --- |
| Tukey HSD | アルファベット (`a`・`b`・`ab` など) | 1 つの行の中で、同じ文字を 1 つも共有しない群どうしに、有意な差があります (p < 0.05)。`a` と `ab` は差が無く、`a` と `b` は差があります |
| Dunnett・Welch の t 検定 | 星 | 対照群と比べて有意な差がある群に、星が付きます。`*` は p < 0.05、`**` は p < 0.01、`***` は p < 0.001 です |

Tukey HSD では、1 マスの文字が 4 文字を超えるタクソンが 1 つでもあると、その図には文字を出しません。文字は `letters.csv` に残ります。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` です。希薄化の前のリード数から、検体ごとに相対存在量を計算し、群ごとに平均しています。
- 検定は、検体ごとの相対存在量 (%) で行っています。
- 深さの下限に届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。

## CSV の列

**`values.csv`** (1 行が 1 タクソン)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| 群の名前の列 | その群の平均の相対存在量 (%) |

**`stats.csv`** (1 行が、1 つのタクソンの、群の 1 組)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `groupA`・`groupB` | 比べた 2 つの群。Dunnett・Welch のときは、代わりに `control` (対照群) と `group` (比べた群) の列になります |
| `n_A`・`n_B` | それぞれの群の検体の数。Dunnett・Welch のときは `n_control`・`n_group` です |
| `p` | p 値。Tukey HSD と Dunnett では、1 つのタクソンの中の組の数に合わせて補正した値です |
| `test` | 使った検定。`tukey_hsd`・`dunnett`・`welch_t`・`not_tested` (検定しなかった) |
| `reason` | 検定しなかった理由 (`n < {{min_n}}` など) |

**`letters.csv`** (1 行が 1 タクソン): `taxon` と、群の名前の列です。中身は、マスの中の文字です。

## 注意

- p 値の補正は、1 つのタクソンの中の組どうしで行っています。タクソンのあいだでは補正していません。たくさんのタクソンを一度に見るので、偶然に有意になるものが混じります。
- 相対存在量は割合です。割合の増減は、菌の量そのものの増減とは限りません。対照群との比較を、割合の偏りを補正して検定した結果は `../11_ancombc/` にあります (対照群を決めたときだけ)。
- 色は対数の目盛なので、色の差が小さく見えても、値は何倍も違うことがあります。値は `values.csv` で確かめてください。
