# 02_rarefaction: レアファクションカーブ

読むリードの数を増やしていったときに、多様性の値がどう変わるかを見る図です。希薄化の深さが足りているかを確かめるために使います。指標は 3 つあり、1 指標につき 1 枚です。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| 希薄化の深さ (横軸の右端) | {{depth}} リード |
| 図に入った検体 | {{samples_used}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `02_rarefaction_observed_features.pdf` | 図。観測された ASV の数 |
| `02_rarefaction_shannon.pdf` | 図。Shannon の多様性指数 |
| `02_rarefaction_faith_pd.pdf` | 図。Faith の系統的多様性 |
| `csv/02_rarefaction_<指標>.values.csv` | 図の線の値 (群と深さごと) |

3 つの指標の意味は、`../03_alpha/README.md` の「4 つの指標」にあります。

## 図の読み方

- **横軸 (Sequencing depth):** 1 検体から無作為に取り出したリードの数です。`5k` は 5,000 本です。右端が希薄化の深さです。
- **線と点:** 群の平均です。点は、値を計算した深さです。
- **うすい帯:** 平均 ± 標準偏差 (SD) です。
- **色:** 群の色です。凡例は `../00_info/00_legend_group.pdf` にあります。
- **見るところ:** 右へ行くほど線が平らになっていれば、その深さで多様性をほぼ拾えています。右端でもまだ上がり続けているなら、深さが足りず、多様性を低く見積もっている可能性があります。
- 検定は付けていません。

## 値の出どころ

- 深さごとに、各検体から無作為にリードを取り出して指標を計算することを 10 回くり返し、検体ごとに平均します。そのあとで、群ごとの平均と SD を出しています。
- 元の値は `../../../Qiime2/HTML_06_alpha-rarefaction.qzv/<指標>.csv` です。
- 深さに届かなかった検体は、この図に入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。

## CSV の列

**`values.csv`** (1 行が、1 つの群の 1 つの深さ)

| 列 | 中身 |
| --- | --- |
| `group` | 群の名前 |
| `depth` | 取り出したリードの数 |
| `n` | その群の検体の数 |
| `mean` | 群の平均 |
| `sd` | 群の標準偏差 |

## 注意

- 線は希薄化の深さで止まります。それより先 (もっと深く読んだらどうなるか) は、この図からは分かりません。
- observed features (ASV の数) は、Shannon や Faith PD より平らになりにくい指標です。まれな ASV が、深く読むほど少しずつ見つかるためです。
