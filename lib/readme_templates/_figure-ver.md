### 見る順のおすすめ

1. `01`・`02` で、データの質を確かめます (リード数は足りているか、外れた検体はどれか)。

3. `07`〜`12` で、どのタクソンが違うのかを見ます。

## すべての図に共通の決まり

- **図と値:** PDF の図と同じ値が、各フォルダの `csv/` にあります。数字を使うときは、図から読み取らず、CSV を使ってください。
- **群の色:** すべての図で同じ色です。凡例は図の中に入れず、`00_info/` に別のファイルで置いています。
- **群の名前:** 図の群の名前に、検体の数 (n) は書いていません。n は CSV にあります。
- **星:** `*` は p < 0.05、`**` は p < 0.01、`***` は p < 0.001 です。有意でない組には何も書きません (n.s. とは書きません)。
- **`n < {{min_n}}`:** 検体の数が、検定に必要な最小の n に満たない群です。検定に入れていません。
- **外れた検体:** リード数が深さの下限に届かなかった検体は、`01` には白抜きで出ますが、`02` 以降の図と解析には入りません。一覧は `../../Qiime2/06_rarefaction/excluded_samples.tsv` です。
- **希薄化:** `02`〜`06` (多様性と距離) は、すべての検体のリード数を希薄化の深さにそろえてから計算しています。`07`〜`12` (タクソンの量) は、そろえる前のリード数から計算しています。
- **乱数:** 乱数を使う計算 (希薄化、並べ替えの検定など) は、種を固定しています。同じ入力からは、同じ結果が出ます。

## タクソンの名前

図と CSV に出るタクソンの名前は、分類 (ドメインから属まで) の文字列を、短く直したものです。

| 名前の形 | 意味 | 例 |
| --- | --- | --- |
| 名前だけ | その階級の名前が付いているタクソン | `Clostridium` |
| `名前;__` | その階級の名前が付いていないタクソン。分かっているいちばん下の階級の名前のあとに、名前の無い階級の数だけ `;__` を付けます | `Peptostreptococcales;__;__` (Peptostreptococcales 目の、科と属が決まっていないもの) |
| `上の階級;名前` | 同じ名前のタクソンが 2 つ以上あるとき。見分けられるように、上の階級の名前を前に付けます | `Streptococcaceae;Enterococcus--other` |
| `名前 (2)` | 上の階級を付けても見分けられないとき。2 つ目から番号を付けます | `Peptoniphilaceae;__ (2)` |

- `uncultured` や `Incertae_Sedis` などは、名前が付いていないものとして扱います。
- `--other` の付いた名前 (例 `Enterococcus--other`) は、分類器 (SILVA) に入っている名前を、そのまま使っています。分類器が、`--other` の付かない同じ名前とは別のまとまりとして持っているものです。別の科に置かれていることもあるので、気になるときは下の対応表で元の分類を確かめてください。
- どの名前が元のどの分類にあたるかは、`00_info/taxa_names_<階級>.csv` で確かめられます。

## 版 (ver) について

- 図の設定 (群、対照群、検定、載せるタクソンの数など) か、もとになる解析の条件が前と違うと、新しい版のフォルダ (`ver2`・`ver3` …) ができます。前の版は、そのまま残ります。
- 設定が同じなら、同じ版のフォルダに描き足します。すでにある図は描き直しません。
- 版ごとの設定の違いは、それぞれの `00_info/settings.yaml` を見比べると分かります。
