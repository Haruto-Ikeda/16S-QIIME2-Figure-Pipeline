# 06_dendrogram: デンドログラム (階層クラスタリング)

菌叢の似ているものどうしを順につないだ、木の形の図です。検体ごとの図と、群ごとの図の 2 種類があります。距離の測り方は 4 つあり、それぞれ 1 枚ずつです。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| つなぎ方 | UPGMA (平均連結法) |
| 希薄化の深さ | {{depth}} リード |
| 図に入った検体 | {{samples_used}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `06_dendrogram_<距離>.pdf` | 図。検体ごとの木 |
| `06_dendrogram-group_<距離>.pdf` | 図。群ごとの木 (群が 3 つ以上のときだけ) |
| `csv/06_dendrogram_<距離>.leaves.csv` | 検体ごとの木の、左からの並び |
| `csv/06_dendrogram_<距離>.linkage.csv` | 検体ごとの木の、つながり方 |
| `csv/06_dendrogram-group_<距離>.leaves.csv` | 群ごとの木の、左からの並び |
| `csv/06_dendrogram-group_<距離>.linkage.csv` | 群ごとの木の、つながり方 |
| `csv/06_dendrogram-group_<距離>.group-distance.csv` | 群どうしの距離の表 |

`<距離>` は `jaccard`・`bray_curtis`・`unweighted_unifrac`・`weighted_unifrac` の 4 つです。それぞれの意味は、`../04_pcoa/README.md` の「4 つの距離」にあります。

## 図の読み方

- **縦軸:** 距離です。2 つの枝がつながる高さが低いほど、その 2 つは似ています。
- **検体ごとの木の下:** 上から、群の色の帯、サブグループの記号 (記号で分ける設定のとき)、検体の名前です。同じ色が横に並んでいれば、その群の検体どうしが似ています。
- **群ごとの木の下:** 群の色の帯と、群の名前です。
- **左右の並び:** 意味はありません。枝は、つなぎ目を軸にして左右を入れ替えても同じ木です。隣にあることでなく、どの高さでつながっているかを見てください。
- 検定は付けていません。群の違いの検定は `../05_permanova/` にあります。

## 2 種類の木の違い

| 木 | もとにする距離 |
| --- | --- |
| 検体ごと | 検体どうしの距離をそのまま使います |
| 群ごと | 群の中心どうしの距離を使います。群の中心は、その群の検体の位置の平均です (PERMANOVA と同じ考え方) |

群ごとの木は、群の中のばらつきを除いた、群の位置だけの比較です。

## 値の出どころ

- 元の値は `../../../Qiime2/07_diversity/<距離>_distance_matrix.tsv` (検体どうしの距離) です。リード数を希薄化の深さにそろえたあとの距離です。
- 深さに届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。

## CSV の列

**検体ごとの `leaves.csv`** (1 行が 1 検体。図の左から順)

| 列 | 中身 |
| --- | --- |
| `leaf_order` | 左から何番目か |
| `sample` | 検体の名前 |
| `group`・`subgroup` | 群とサブグループの名前 |
| `label` | 図の色の帯に使った群 |

**群ごとの `leaves.csv`** (1 行が 1 群。図の左から順)

| 列 | 中身 |
| --- | --- |
| `leaf_order` | 左から何番目か |
| `group` | 群の名前 |
| `n` | その群の検体の数 |
| `mean_within_group_distance` | その群の中の、検体どうしの距離の平均 (群の中のばらつきの目安) |

**`linkage.csv`** (1 行が、木のつなぎ目 1 つ。低い方から順)

| 列 | 中身 |
| --- | --- |
| `child1`・`child2` | つないだ 2 つの番号。検体 (群) の番号は 0 から始まり、もとにした距離の表 (検体ごとは `<距離>_distance_matrix.tsv`、群ごとは `group-distance.csv`) の並び順です。検体 (群) の数以上の番号は、それまでにできたかたまりです (数 + 行の順番。行は 0 から数えます) |
| `height` | つながった高さ (距離) |
| `n_samples` (群ごとは `n_groups`) | そのかたまりに入っている検体 (群) の数 |
| `method` | つなぎ方 |
| `group_distance` | 群どうしの距離の決め方。群ごとの CSV だけにあります |

**`group-distance.csv`:** 行と列が群で、中身が群の中心どうしの距離です。

## 注意

- 木の形は、距離の測り方とつなぎ方で変わります。1 枚の木だけで結論を出さず、4 つの距離と、04 の PCoA をあわせて見てください。
- 群ごとの木は、検体の少ない群では 1 検体の位置に大きく左右されます。
