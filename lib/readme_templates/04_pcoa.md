# 04_pcoa: PCoA (主座標分析)

検体どうしの菌叢の似かよりを、散布図にした図です。菌叢が似ている検体ほど、近くに描かれます。距離の測り方は 4 つあり、それぞれについて 2 種類の図があります。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| 希薄化の深さ | {{depth}} リード |
| 図に入った検体 | {{samples_used}} |
| 色 | {{pcoa_color}} |
| 記号 | {{pcoa_marker}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `04_pcoa_<距離>.pdf` | 図。第 1 軸 (PCo1) と第 2 軸 (PCo2) の散布図 |
| `04_pcoa-matrix_<距離>.pdf` | 図。第 1〜4 軸のすべての組み合わせ (6 マス) |
| `csv/04_pcoa_<距離>.values.csv`・`csv/04_pcoa-matrix_<距離>.values.csv` | 図の点の座標 (検体ごと) |
| `csv/04_pcoa_<距離>.ellipses.csv`・`csv/04_pcoa-matrix_<距離>.ellipses.csv` | 図の楕円の形 (群ごと) |

`<距離>` は `jaccard`・`bray_curtis`・`unweighted_unifrac`・`weighted_unifrac` の 4 つです。

## 4 つの距離

| 距離 | 見ているもの | 向いている場面 |
| --- | --- | --- |
| Jaccard | ASV がいるか、いないかだけ | 構成する菌の顔ぶれの違いを見る |
| Bray–Curtis | ASV の量の違い | 多い菌の増減を見る |
| Unweighted UniFrac | いるか、いないかに、系統の近さを加えたもの | 系統の離れた菌の出入りを見る |
| Weighted UniFrac | 量の違いに、系統の近さを加えたもの | 多い菌の増減を、系統も考えて見る |

どの距離も 0 が「同じ」で、大きいほど違います。距離によって見え方が変わるのは、ふつうのことです。

## 図の読み方

- **点:** 1 つの点が 1 検体です。点どうしが近いほど、菌叢が似ています。
- **軸の % :** その軸が、検体のあいだの違い全体のうち、どれだけを表しているかです (寄与率)。% の小さい軸での離れ方は、あまり重く見ないでください。
- **楕円:** 群ごとの 95% データ楕円です。その群の検体が散らばる範囲の目安です。検体が 3 つに満たない群には描きません。
- **色と記号:** 色は群です。サブグループを記号で分ける設定のときは、記号がサブグループです。凡例は `../00_info/` にあります。
- **うすい十字の線:** 原点 (0, 0) です。縦と横は同じ縮尺です。
- **`04_pcoa-matrix`:** 横の並びが横軸 (左から PCo1・PCo2・PCo3)、縦の並びが縦軸 (上から PCo2・PCo3・PCo4) です。左上のマスが `04_pcoa` と同じ図です。すべてのマスが同じ範囲です。
- 検定は付けていません。群の違いの検定は `../05_permanova/` にあります。

## 値の出どころ

- 距離は、すべての検体のリード数を希薄化の深さにそろえたあとで計算しています。
- 元の値は `../../../Qiime2/07_diversity/<距離>_pcoa_results.tsv` です。検体どうしの距離そのものは、同じフォルダの `<距離>_distance_matrix.tsv` です。
- 深さに届かなかった検体は、この図に入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。

## CSV の列

**`values.csv`**

| 列 | 中身 |
| --- | --- |
| `sample` | 検体の名前 |
| `group` | 群の名前 |
| `subgroup` | サブグループの名前 |
| `PCo1`・`PCo2` (matrix は `PCo4` まで) | 各軸の座標 |

**`ellipses.csv`** (1 行が、1 つの群の楕円)

| 列 | 中身 |
| --- | --- |
| `pair` | どの軸の組み合わせか (`PCo1xPCo2` など)。matrix の CSV だけにあります |
| `group` | 群の名前 |
| `cx`・`cy` | 楕円の中心 (群の検体の座標の平均) |
| `width`・`height` | 楕円の長い方と短い方の、端から端までの長さ |
| `angle` | 楕円の傾き (度) |
| `n` | その群の検体の数 |
| `method`・`level` | 楕円の作り方 (`data_ellipse_chi2`) と、範囲 (0.95) |

検体が 3 つに満たない群は、`group` と `n` だけが入ります。

## 注意

- 楕円は、検体の散らばりの目安です。平均の信頼区間ではありません。楕円が重なっていても差が無いとは言えず、離れていても差があるとは言えません。
- 検体の少ない群の楕円は、1 検体の位置で大きく形が変わります。
- 軸の向き (正と負) には意味がありません。左右や上下が入れ替わっても、同じ結果です。
