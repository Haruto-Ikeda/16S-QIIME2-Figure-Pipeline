## 工程ごとのフォルダ

| フォルダ | 工程 | 主な中身 |
| --- | --- | --- |
| `01_metadata/` | 検体の表を作る | 検体の ID、名前、群の対応表 |
| `02_import/<ラン>/` | 生データ (FASTQ) を読み込む | 読み込んだリード (`demux.qza`)。生データと同じくらいの大きさがあります |
| `03_dada2/<ラン>/` | 品質の確認、ペアの結合、キメラの除去 (DADA2) | ASV の表、代表配列、検体ごとに残ったリードの数 (`denoising-stats.tsv`) |
| `03_merge/` | ランをつなげる (ランが 2 つ以上のときだけ) | つなげた ASV の表と代表配列 |
| `04_relabel/` | 検体の ID を、検体の名前に付け替える | 名前を付け替えた ASV の表 (`table_cn.qza`) |
| `05_phylogeny/` | 系統樹を作る | 代表配列の系統樹 (`rooted-tree.qza`) |
| `06_rarefaction/` | 希薄化の深さを決める | 深さ、外れた検体の一覧、レアファクションカーブ |
| `07_diversity/` | α多様性と β多様性を計算する | 多様性の値、検体どうしの距離、PCoA の座標 |
| `09_taxonomy/` | 菌を同定し、階級ごとにまとめる | ASV ごとの分類、階級ごとのリード数の表 |
| `HTML_<工程>_<名前>.qzv/` | QIIME 2 の画面をブラウザで見られる形にしたもの | 中の `index.html` をブラウザで開きます |

08 (分類器の確認) は、フォルダを作りません。

## よく使うファイル

表計算ソフトで開けるファイルです。`.tsv` はタブ区切りの表です。

| ファイル | 中身 |
| --- | --- |
| `01_metadata/sample-metadata.txt` | 検体の ID (`#SampleID`) と、検体の名前 (`newID`)、群、サブグループの対応 |
| `03_dada2/<ラン>/denoising-stats.tsv` | 検体ごとに、各段階で残ったリードの数。`non-chimeric` が最後に残った数です |
| `06_rarefaction/sampling_depth.txt` | 希薄化の深さ |
| `06_rarefaction/excluded_samples.tsv` | 深さの下限に届かず、解析から外れた検体の一覧 (外れた検体が無ければ、見出しの行だけです) |
| `07_diversity/<指標>_vector.tsv` | 検体ごとの α多様性の値 (`observed_features`・`shannon`・`faith_pd`・`evenness`) |
| `07_diversity/<距離>_distance_matrix.tsv` | 検体どうしの距離の表 (`jaccard`・`bray_curtis`・`unweighted_unifrac`・`weighted_unifrac`) |
| `07_diversity/<距離>_pcoa_results.tsv` | PCoA の結果 (各軸の寄与率と、検体の座標) |
| `09_taxonomy/rep-seqs_classified.tsv` | ASV ごとの分類と、その確からしさ |
| `09_taxonomy/collapsed_table_<階級>.tsv` | 検体ごと・タクソンごとのリード数 (希薄化の前)。相対存在量のもとになる表です |

`HTML_09_taxa-bar-plots.qzv/` の中の `level-<番号>.csv` にも、階級ごとのリード数の表があります。番号と階級の対応は、下の「階級と番号」を見てください。

## 検体の ID と名前

- 02・03 のファイルでは、検体はシーケンスのときの ID (例 `M0001P0001N0001`) で書かれています。
- 04 より後のファイルと、図では、検体の名前 (例 `Control_1`) で書かれています。
- 対応は `01_metadata/sample-metadata.txt` で確かめられます。

## ファイルの種類

| 拡張子 | 中身 | 開き方 |
| --- | --- | --- |
| `.qza` | QIIME 2 のデータ。QIIME 2 の次の工程に渡すためのファイルです | QIIME 2 で使います。中身を見るだけなら、同じ名前の `.tsv` があるものはそちらを見てください |
| `.qzv` (ファイル) | QIIME 2 の、見るための結果 | https://view.qiime2.org に、ファイルをドラッグして開きます |
| `HTML_….qzv/` (フォルダ) | 上の `.qzv` を、あらかじめ開いた形にしたもの | 中の `index.html` をブラウザで開きます。インターネットにつながなくても見られます |
| `.tsv`・`.txt`・`.csv` | 表 | 表計算ソフトやテキストエディタで開きます |
| `_conditions.json` | その工程を、どの条件で実行したかの記録。パイプラインが、やり直しが要るかを判断するのに使います | 書き換えたり、消したりしないでください |

## 階級と番号

`HTML_09_taxa-bar-plots.qzv/` の画面の Level と、`level-<番号>.csv` の番号は、次の階級にあたります (同梱の SILVA 144 の分類器の場合)。

| 番号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 階級 | Domain | Kingdom | Phylum | Class | Order | Family | Genus | Species |

- SILVA 144 には Kingdom の階層があるので、古い版 (SILVA 138 など) の番号とは 1 つずれます。`level-6.csv` は科、`level-7.csv` は属です。
- 分類器が属までのものなら、番号は 7 までです。

## 絞り込みの実行のとき

解析を終えた別の実験 (親) の結果から、一部の検体だけを選んで図を描き直した実行では、このフォルダの中身が少なくなります。

- 入っているのは、選んだ検体だけにした表 (`.tsv`・`.txt`・`.csv`) です。`.qza` と `.qzv` のファイル、02・04・05 のフォルダ、ブラウザで見る画面 (`index.html`) はありません。それらは親の実験のフォルダにあります。
- `_parent.json` は、どの親の、どの条件の結果を使ったかの記録です。書き換えたり、消したりしないでください。
- 希薄化の深さと、検体どうしの距離は、親と同じ値です。PCoA の座標は、選んだ検体で計算し直しています。

## 注意

- このフォルダのファイルを書き換えたり、名前を変えたり、一部だけ消したりしないでください。次に実行したときに、パイプラインが正しく続きから進めなくなります。
- `02_import/` は、ほかのフォルダよりずっと大きくなります。図と表を見るだけなら、使いません。
