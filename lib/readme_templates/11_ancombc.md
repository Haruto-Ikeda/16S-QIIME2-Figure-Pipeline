# 11_ancombc: ANCOM-BC (対照群に対して増えた・減ったタクソン)

対照群と比べて、量が増えたタクソンと減ったタクソンを探した結果の図です。割合 (相対存在量) の偏りを補正する方法 (ANCOM-BC2) を使っています。階級 (属など) ごとに 1 枚です。対照群を決めたときだけ作られます。

| --- | --- |

| 比べた群 | {{comps}} |
| 載せるタクソンの数 | {{ancombc_top_n}} |
| 計算に必要な最小の n | {{min_n}} |
| 計算に入った検体 | {{samples_used}} |

有意なタクソンが 1 つも無いときは、図は作られず、`all.csv` だけができます。

## 図の読み方

- **行:** タクソンです。名前は右に書いてあります。
- **列:** 群です。下に、群の色の帯と名前があります。
- **対照群の列 (色の付いたマスと数字):** 対照群での、平均の相対存在量 (%) です。そのタクソンがもともとどれくらい多いかの目安です。`<0.1` は 0.1% 未満です。色の目盛は左端のバー (Relative abundance) です。
- **ほかの群の列 (円):** 対照群と比べた結果です。
  - **円の色 (Log fold change):** 増減の向きと大きさです。赤は対照群より増えた、青は減ったことを示し、濃いほど変化が大きいことを示します。
  - **円の大きさ:** q 値 (補正したあとの p 値) の 3 段階です。大きいほど q 値が小さく、`_legend.pdf` に見本があります。
  - **灰色の小さな点:** 有意でない組です。
  - **空欄:** 検定されなかった組です (下の「検定されない組」を見てください)。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は計算に入れず、群の色の帯の中に `n < {{min_n}}` と書きます。その列は空欄になります。

### Log fold change の読み方

自然対数 (ln) で表した、対照群に対する倍率です。

| 値 | 倍率 |
| --- | --- |
| 0.69 | 2 倍 |
| 1.1 | 3 倍 |
| 2.3 | 10 倍 |
| −0.69 | 2 分の 1 |
| −2.3 | 10 分の 1 |

## 有意の決め方

次の 2 つを両方満たした組を、有意としています (`sig` の列)。

1. q 値が 0.05 より小さい (`diff` の列)。
2. 感度解析を通った (`passed_ss` の列)。0 のリード数に小さな数 (0.1・0.5・1) を足して計算し直しても、結果が変わらないことを確かめる解析です。0 の多いタクソンで、見かけの有意が出るのを防ぎます。

## 図に載せるタクソンの選び方

1. 比べた群ごとに、有意なタクソンを、変化の大きい順 (Log fold change の絶対値の大きい順) に並べます。
2. 比べた群から順番に 1 つずつ取り、全体で、載せる数になるまで続けます。
3. 行の並びは、選ばれた群ごとにまとめ、その中で、増えたもの (大きい順)、減ったもの (大きい順) の順です。

図に載っているのは、有意なタクソンの一部です。全部の結果は `all.csv` にあります。

## 検定されない組

ある群のすべての検体で 0 だったタクソン (構造的ゼロ) は、検定されません。その群との比較だけでなく、そのタクソンのほかの群との比較も、検定されません。「片方の群にしかいない」タクソンは、この図でなく、`../09_venn-upset/` と `../10_taxon-bar/` で確かめてください。`all.csv` では、`struc_zero` か `not_tested` の列が `True` になります。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` (検体ごと・タクソンごとのリード数) です。希薄化の前のリード数を、そのまま ANCOM-BC2 に渡しています。
- 深さの下限に届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。

## CSV の列

**`all.csv`** (1 行が、1 つのタクソンの、対照群と 1 つの群の比較)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `control`・`group` | 対照群と、比べた群 |
| `n_control`・`n_group` | それぞれの群の、計算に使った検体の数 |
| `ln_fc` | Log fold change (自然対数)。正なら対照群より増えた、負なら減った |
| `log_base` | 対数の底 (`natural (ln)`) |
| `SE` | `ln_fc` の標準誤差 |
| `W` | 検定の統計量 (`ln_fc` ÷ `SE`) |
| `pvalue` | p 値 (補正の前) |
| `qvalue` | q 値 (補正のあと) |
| `diff` | `True` なら q 値が 0.05 より小さい |
| `passed_ss` | `True` なら感度解析を通った |
| `sig` | `True` なら有意 (`diff` と `passed_ss` の両方が `True`)。図の円は、この列で決めています |
| `not_tested` | `True` なら、そのタクソンのほかの群が構造的ゼロだったため、検定されなかった組 |
| `struc_zero` | `True` なら、この組のどちらかの群が構造的ゼロ |
| `zero_in_control`・`zero_in_group` | 対照群、比べた群が、それぞれ構造的ゼロかどうか |
| `method`・`ancombc_version` | 計算の方法と、R の ANCOMBC の版 |
| `pseudo` | 計算のときに 0 に足した数 (0 = 足していない) |
| `sensitivity` | 感度解析で足した数 |
| `p_adjust` | q 値の補正の方法 (BH = Benjamini–Hochberg) |
| `mdfdr` | 複数の群と比べるときの補正の方法 |
| `prv_cut` | 出現率で外す基準 (0 = 外していない) |
| `neg_lb` | 構造的ゼロの判定に、下限を使う方法を使ったか (`False` = 使っていない) |
| `seed` | 乱数の種 |

**`plotted.csv`** (図に載せたタクソンだけ): `all.csv` の結果の列に、`mean_relative_abundance_<対照群>` (対照群での平均の相対存在量 %) が付きます。

## 注意

- 図に載るタクソンは、変化の大きい順に選んでいます。もともと少ないタクソンは、少しの違いで倍率が大きくなるので、選ばれやすくなります。対照群の列の数字で、もともとの量を確かめてください。量の多いタクソンから見たいときは `../12_ancombc-summary/` を見てください。
- 検体が少ないと、検出できる違いは限られます。有意でないことは、差が無いことの証明ではありません。
- 対照群の検体が {{min_n}} つに満たないときは、図も CSV も作られません。
- 比べる群が 1 つだけ (全部で 2 群) のときは、Dunnett 型でなく、2 群の比較として計算します (`method` の列が `ANCOM-BC2 primary` になります)。
