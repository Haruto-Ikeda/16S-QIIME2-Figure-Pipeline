## 図の読み方

- **縦軸 (Non-chimeric reads):** 品質の確認、ペアの結合、キメラの除去 (DADA2) を通って最後に残ったリードの数です。`20k` は 20,000 本です。
- **点:** 1 つの点が 1 検体です。重ならないように、横にずらしてあります。
- **白抜きの点:** リード数が深さの下限に届かず、02 以降の図と解析から外れた検体です。
- **横線とエラーバー:** 横線は群の平均、エラーバーは標準偏差 (SD) です。白抜きの検体も含めて計算しています。
- **破線 (`depth {{depth}}`):** 希薄化の深さです。02 以降では、すべての検体のリード数をこの数にそろえてから比べます。
- **点線:** 深さの下限です。これより少ない検体は外れます。
- **かっこと星:** 有意な差があった群の組に、かっこを引いて星を付けます。`*` は p < 0.05、`**` は p < 0.01、`***` は p < 0.001 です。星の無い組は、有意な差がありません (n.s. とは書きません)。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は検定に入れず、群の上に `n < {{min_n}}` と書きます。
- **色:** 群の色です。凡例は `../00_info/00_legend_group.pdf` にあります。

## 希薄化の深さの決め方

1. リード数が深さの下限以上の検体を残します。
2. 残った検体のうち、いちばん少ないリード数を、希薄化の深さにします。

深さの下限は、実行の設定 (`diversity.sampling_depth_floor`) で決めた値です。外れた検体の一覧は `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。

## 値の出どころ

- 元の値は `../../../Qiime2/03_dada2/<ラン>/denoising-stats.tsv` の `non-chimeric` の列です。ランが 2 つ以上あるときは、つなげた `../../../Qiime2/03_merge/denoising-stats.tsv` です。
- この図だけは、希薄化の前の値です。

## CSV の列

**`values.csv`**

| 列 | 中身 |
| --- | --- |
| `sample-id` | 検体の ID (シーケンスのときの ID) |
| `group` | 群の名前 |
| `non-chimeric` | 最後に残ったリードの数 |
| `excluded` | `True` なら、以降の解析から外れた検体 (図では白抜き) |

**`stats.csv`** (1 行が、群の 1 組)

| 列 | 中身 |
| --- | --- |
| `groupA`・`groupB` | 比べた 2 つの群 |
| `n_A`・`n_B` | それぞれの群の検体の数 |
| `p` | p 値。Tukey HSD と Dunnett では、組の数に合わせて補正した値です。検定しなかった組は空です |
| `test` | 使った検定。`tukey_hsd`・`dunnett`・`welch_t`・`not_tested` (検定しなかった) |
| `reason` | 検定しなかった理由 (`n < {{min_n}}` など) |
| `stars` | 図に付けた星。有意でなければ空です |
| `metric` | 比べた値の名前 (`non-chimeric`) |
| `dunnett_seed` | Dunnett の計算に使った乱数の種。Dunnett のときだけ入ります |

## 注意

- この図の検定は、リード数に群の間で偏りが無いかを確かめるためのものです。菌叢の違いを見る検定ではありません。
- リード数に大きな偏りがある群は、希薄化で多くのリードを捨てることになります。02 のレアファクションカーブで、深さが足りているかを確かめてください。
