# 10_taxon-bar: タクソン別の棒 (相対存在量と検定)

タクソン 1 つにつき 1 枚、群ごとの相対存在量を棒で示した図です。気になるタクソンを 1 つずつ確かめるために使います。枚数が多いので、名前でファイルを探してください。

| 項目 | 値 |
| --- | --- |
| 階級 | {{ranks}} |
| 図の枚数 | {{taxon_bar_count}} |
| 検定 | {{stats_method}} |
| 検定に必要な最小の n | {{min_n}} |
| 図に入った検体 | {{samples_used}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `10_taxon-bar_<階級>_<タクソン>.pdf` | 図。タクソンごとに 1 枚 |
| `csv/10_taxon-bar_<階級>.files.csv` | タクソンの名前と、図のファイル名の対応 |
| `csv/10_taxon-bar_<階級>.values.csv` | 棒の値 (タクソンと群ごとの平均と SD) |
| `csv/10_taxon-bar_<階級>.stats.csv` | 検定の結果 (タクソンと、群の組ごと) |

### 図のファイルの探し方

ファイル名の `<タクソン>` は、タクソンの名前の中の記号 (`;` や空白など) を `-` に置き換え、60 文字までに切ったものです。名前から見つからないときは、`files.csv` でタクソンの名前を探すと、ファイル名が分かります。

## 図の読み方

- **タイトル:** タクソンの名前です。
- **縦軸 (Relative abundance):** 相対存在量 (%) です。その検体のリード全体のうち、そのタクソンのリードが占める割合です。
- **棒:** 群の平均です。うすい色で塗ってあります。
- **点:** 1 つの点が 1 検体です。
- **エラーバー:** 標準偏差 (SD) です。
- **かっこと星:** 有意な差があった群の組に、かっこを引いて星を付けます。`*` は p < 0.05、`**` は p < 0.01、`***` は p < 0.001 です。星の無い組は、有意な差がありません。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は検定に入れず、群の上に `n < {{min_n}}` と書きます。
- **縦書きの `< {{floor}} reads`:** すべての検体のリード数が深さの下限に届かず、解析に使える検体が残らなかった群です。群の名前は残し、棒の代わりにこの文字を書きます。検定には入らず、`values.csv`・`stats.csv` にも行はありません。
- **色:** 群の色です。凡例は `../00_info/00_legend_group.pdf` にあります。
- **縦軸の範囲:** タクソンごとに違います。2 枚の図を見比べるときは、目盛の数字を確かめてください。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` (検体ごと・タクソンごとのリード数) です。希薄化の前のリード数から、検体ごとに相対存在量を計算しています。
- 深さの下限に届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。

## CSV の列

**`files.csv`**

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `file` | 図のファイル名 |

**`values.csv`** (1 行が、1 つのタクソンの 1 つの群)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `group` | 群の名前 |
| `n` | その群の検体の数 |
| `mean` | 相対存在量 (%) の平均 |
| `sd` | 相対存在量 (%) の標準偏差 |

**`stats.csv`** (1 行が、1 つのタクソンの、群の 1 組)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `groupA`・`groupB` | 比べた 2 つの群 |
| `n_A`・`n_B` | それぞれの群の検体の数 |
| `p` | p 値。Tukey HSD と Dunnett では、1 つのタクソンの中の組の数に合わせて補正した値です。検定しなかった組は空です |
| `test` | 使った検定。`tukey_hsd`・`dunnett`・`welch_t`・`not_tested` (検定しなかった) |
| `reason` | 検定しなかった理由 (`n < {{min_n}}`・`全検体で 0`・`両群とも全検体で 0`) |
| `note` | 補正の範囲のことわり書き (タクソンのあいだの補正なし) |

## 注意

- **タクソンのあいだでは、p 値を補正していません。** 数百のタクソンを 1 つずつ検定しているので、本当は差が無くても、偶然に有意になるものが混じります。この図は、気になるタクソンの様子を確かめるために使い、「有意だったタクソンを全部拾う」使い方はしないでください。
- 対照群と比べて増えた・減ったタクソンを、補正をかけて探した結果は `../11_ancombc/` にあります (対照群を決めたときだけ)。
- 相対存在量は割合です。割合の増減は、菌の量そのものの増減とは限りません。
- ほとんどの検体で 0 のタクソンは、少数の検体の値だけで平均と検定が決まります。点の並びを見て判断してください。
