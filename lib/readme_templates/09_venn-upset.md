# 09_venn-upset: ベン図と UpSet (群のあいだのタクソンの重なり)

それぞれの群で検出されたタクソンが、群のあいだでどれだけ重なっているかを示した図です。ベン図と UpSet は、同じ内容を別の形で描いたものです。階級 (属など) ごとに 1 枚ずつです。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| 階級 | {{ranks}} |
| 「その群にいる」の決め方 | 群のすべての検体で 1 リード以上 |
| 図に入った検体 | {{samples_used}} |
| ベン図 | {{venn}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `09_venn_<階級>.pdf` | 図。ベン図 (群が 2〜5 個のときだけ) |
| `09_upset_<階級>.pdf` | 図。UpSet |
| `csv/09_venn-upset_<階級>.presence.csv` | タクソンごとに、どの群にいるか |
| `csv/09_venn-upset_<階級>.intersections.csv` | 重なりごとの、タクソンの数と名前 |

## 「その群にいる」の決め方

そのタクソンが、**群のすべての検体**で 1 リード以上あるときに、「その群にいる」とします。1 検体でも 0 なら「いない」とします。厳しめの決め方です。

## 図の読み方

**ベン図**

- 1 つの円 (楕円) が 1 つの群です。色は群の色で、凡例は `../00_info/00_legend_group.pdf` にあります。群の名前は図の中に書いていません。
- 数字は、その場所にあたるタクソンの数です。円が重なった場所の数字は、重なっている群のすべてにいて、ほかの群にはいないタクソンの数です。

**UpSet**

- 左の点の並びの 1 行が、重なり方の 1 通りです。色の付いた点が、その重なりに入る群です。灰色の点の群には、いません。
- 右の横棒と数字が、その重なりにあたるタクソンの数です。数の多い順に、上から並んでいます。
- たとえば、A と B の点だけに色が付いた行は、「A と B にいて、ほかの群にはいない」タクソンの数です。
- 群が 6 個以上のときはベン図を描かないので、UpSet を見てください。

どの群にも「いる」と言えないタクソンは、どちらの図にも出ません。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` (検体ごと・タクソンごとのリード数) です。希薄化の前のリード数で判定しています。
- 深さの下限に届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。

## CSV の列

**`presence.csv`** (1 行が 1 タクソン。すべてのタクソンが入ります)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| 群の名前の列 | `True` なら、その群にいる |

**`intersections.csv`** (1 行が、重なり方の 1 通り。UpSet の上から順)

| 列 | 中身 |
| --- | --- |
| `groups` | その重なりに入る群 (` & ` で区切ります) |
| `n_taxa` | タクソンの数 |
| `taxa` | タクソンの名前 (`; ` で区切ります) |

## 注意

- 「いない」は、検出されなかったという意味です。その菌がいないことの証明ではありません。少ない菌は、読んだリードの数しだいで、検出されたりされなかったりします。
- 検体の多い群ほど、「すべての検体にいる」という条件が厳しくなります。検体数の違う群を比べるときは、その分を割り引いて見てください。
- この図は、量を見ていません。ごく少ないタクソンも、多いタクソンも、同じ 1 つとして数えます。量の違いは 07・08・10 を見てください。
