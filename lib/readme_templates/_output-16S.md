## まず見るところ

1. `figure/{{ver}}/README.md` を開きます。`{{ver}}` が、最後に実行したときの設定で描いた図です (番号のいちばん大きい版とは限りません)。図の一覧と、すべての図に共通の決まりが書いてあります。
2. 見たい図のフォルダを開き、PDF を見ます。読み方は、そのフォルダの `README.md` にあります。
3. 数字が要るときは、図のフォルダの中の `csv/` を見ます。

## figure の版 (ver)

- `figure/` の中は、`ver1`・`ver2` … と、版ごとのフォルダに分かれています。
- 図の設定 (群の分け方、対照群、検定の方法など) を変えて実行すると、新しい版ができます。前の版は残るので、見比べられます。
- それぞれの版の設定は、`figure/ver<番号>/00_info/settings.yaml` に記録されています。

## logs の中身

実行するたびに、2 つのファイルができます。名前の先頭は、実行を始めた日時です。

| ファイル | 中身 |
| --- | --- |
| `<日時>_16S.log` | 実行の記録。使った設定、工程ごとの結果、注意と注記が書いてあります |
| `<日時>_env.txt` | 実行したときの、ソフトウェアの版の一覧 |

図が作られなかった理由や、検定から外れた群などは、ログの注記に書いてあります。結果を発表や論文に使うときは、ログとこのフォルダを一緒に残しておくと、あとから条件を確かめられます。

## 解析の流れ

| 工程 | すること | 出力 |
| --- | --- | --- |
| 01 | 検体の表を作る | `Qiime2/01_metadata/` |
| 02 | 生データ (FASTQ) を読み込む | `Qiime2/02_import/` |
| 03 | 品質の確認、ペアの結合、キメラの除去 (DADA2) をして、ASV (配列の種類) の表を作る | `Qiime2/03_dada2/` |
| 04 | 検体の ID を、検体の名前に付け替える | `Qiime2/04_relabel/` |
| 05 | 系統樹を作る | `Qiime2/05_phylogeny/` |
| 06 | 希薄化の深さを決める | `Qiime2/06_rarefaction/` |
| 07 | α多様性と β多様性を計算する | `Qiime2/07_diversity/` |
| 08 | 分類器を確かめる | (フォルダはありません) |
| 09 | 菌を同定し、階級ごとにまとめる | `Qiime2/09_taxonomy/` |
| 10 | 図を描く | `figure/` |

## 言葉の説明

| 言葉 | 意味 |
| --- | --- |
| ASV | 配列の種類。1 塩基の違いまで区別した、菌の最小の単位です |
| リード | シーケンサーが読んだ配列 1 本 |
| 希薄化 | すべての検体のリードの数を、同じ数にそろえること。リードの数の違いが、多様性の値に影響しないようにします |
| 希薄化の深さ | そろえるリードの数 |
| タクソン | 菌の分類群 (属、科など) |
| 相対存在量 | その検体のリード全体のうち、そのタクソンのリードが占める割合 (%) |
| α多様性 | 1 つの検体の中の、菌の多様さ |
| β多様性 | 検体と検体のあいだの、菌叢の違い |
| 群・サブグループ | 検体のまとまり。実行の設定で決めたものです |
| 対照群 | 比べるときの基準にする群 |
