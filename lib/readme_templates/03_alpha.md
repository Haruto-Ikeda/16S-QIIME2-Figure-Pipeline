# 03_alpha: α多様性

検体ごとの α多様性 (1 つの検体の中の多様さ) を、群ごとに並べた図です。指標は 4 つあり、1 指標につき 1 枚です。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| 検定 | {{stats_method}} |
| 検定に必要な最小の n | {{min_n}} |
| 希薄化の深さ | {{depth}} リード |
| 図に入った検体 | {{samples_used}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `03_alpha_observed_features.pdf` | 図。観測された ASV の数 |
| `03_alpha_shannon.pdf` | 図。Shannon の多様性指数 |
| `03_alpha_faith_pd.pdf` | 図。Faith の系統的多様性 |
| `03_alpha_evenness.pdf` | 図。Pielou の均等度 |
| `csv/03_alpha_<指標>.values.csv` | 図の点の値 (検体ごと) |
| `csv/03_alpha_<指標>.stats.csv` | 検定の結果 (群の組ごと) |

## 4 つの指標

| 指標 | 見ているもの | 値の読み方 |
| --- | --- | --- |
| observed features | 種類の数。検出された ASV (配列の種類) の数 | 大きいほど種類が多い |
| Shannon | 種類の数と、偏りの小ささの両方 | 大きいほど多様。種類が多く、偏りが小さいと大きくなる (対数の底は 2) |
| Faith PD | 系統の広がり。検出された ASV を系統樹でつないだ枝の長さの合計 | 大きいほど、系統の離れた菌を含む |
| evenness | 偏りの小ささ。0〜1 | 1 に近いほど、どの ASV も同じくらいの量。少数の ASV に偏ると 0 に近づく |

## 図の読み方

- **点:** 1 つの点が 1 検体です。重ならないように、横にずらしてあります。
- **横線とエラーバー:** 横線は群の平均、エラーバーは標準偏差 (SD) です。
- **かっこと星:** 有意な差があった群の組に、かっこを引いて星を付けます。`*` は p < 0.05、`**` は p < 0.01、`***` は p < 0.001 です。星の無い組は、有意な差がありません (n.s. とは書きません)。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は検定に入れず、群の上に `n < {{min_n}}` と書きます。点と平均は描きます。
- **色:** 群の色です。凡例は `../00_info/00_legend_group.pdf` にあります。

## 値の出どころ

- 値は、すべての検体のリード数を希薄化の深さにそろえたあとで計算しています。リード数の違いは、値に影響しません。
- 深さに届かなかった検体は、この図に入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- 元の値は `../../../Qiime2/07_diversity/<指標>_vector.tsv` です。`values.csv` は、これに群の名前を付けたものです。

## CSV の列

**`values.csv`**

| 列 | 中身 |
| --- | --- |
| `sample` | 検体の名前 |
| `group` | 群の名前 |
| `<指標>` | 指標の値 |

**`stats.csv`** (1 行が、群の 1 組)

| 列 | 中身 |
| --- | --- |
| `groupA`・`groupB` | 比べた 2 つの群 |
| `n_A`・`n_B` | それぞれの群の検体の数 |
| `p` | p 値。Tukey HSD と Dunnett では、組の数に合わせて補正した値です。検定しなかった組は空です |
| `test` | 使った検定。`tukey_hsd`・`dunnett`・`welch_t`・`not_tested` (検定しなかった) |
| `reason` | 検定しなかった理由 (`n < {{min_n}}` など) |
| `stars` | 図に付けた星。有意でなければ空です |
| `metric` | 指標の名前 |
| `dunnett_seed` | Dunnett の計算に使った乱数の種。Dunnett のときだけ入ります |

## 注意

- p 値の補正は、1 つの指標の中の組どうしで行っています。4 つの指標の間では補正していません。
- 検定に残る群が 2 つだけになったときは、Tukey HSD でなく Welch の t 検定を使います (`test` の列が `welch_t` になります)。
