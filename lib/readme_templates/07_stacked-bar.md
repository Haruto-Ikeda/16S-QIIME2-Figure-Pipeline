# 07_stacked-bar: 積み上げ棒 (菌叢の組成)

どのタクソン (菌の分類群) がどれだけの割合を占めているかを、積み上げた棒で示した図です。群の平均の図と、検体ごとの図の 2 種類があります。階級 (属など) ごとに 1 枚ずつです。

| 項目 | 値 |
| --- | --- |
| 階級 | {{ranks}} |
| 載せるタクソンの数 | 上位 {{top_n}} (残りは Others) |
| 図に入った検体 | {{samples_used}} |

| ファイル | 中身 |
| --- | --- |
| `07_stacked-group_<階級>.pdf` | 図。群の平均 |
| `07_stacked-group_<階級>_legend.pdf` | 上の図の、タクソンの色の凡例 |
| `07_stacked-sample_<階級>.pdf` | 図。検体ごと |

## 図の読み方

- **縦軸 (Relative abundance):** 相対存在量 (%) です。その検体のリード全体のうち、そのタクソンのリードが占める割合です。1 本の棒は、合計が 100% です。
- **色:** タクソンです。凡例は、同じ名前に `_legend` の付いた PDF です。2 種類の図で、載せるタクソンと色は同じです。
- **積む順:** いちばん多いタクソンがいちばん下で、Others (上位に入らなかったタクソンの合計) がいちばん上です。凡例は、棒と同じ上下の順に並んでいます。
- **棒の下:** 群の色の帯と、名前です。検体ごとの図では、サブグループの記号 (記号で分ける設定のとき) と検体の名前が付きます。群の色の凡例は `../00_info/00_legend_group.pdf` にあります。
- **検体ごとの図の並び:** 群の順、サブグループの順、検体の名前の末尾の番号の順です。
- **枠だけの棒 (`< {{floor}} reads`):** リード数が深さの下限に届かず、解析から外れた検体です。検体ごとの図にだけ出ます。
- 検定は付けていません。タクソンごとの検定は `../10_taxon-bar/`、対照群との比較は `../11_ancombc/` にあります。

## 上位のタクソンの選び方

1. 検体ごとに、相対存在量を計算します。
2. 群ごとに平均します。
3. 群の平均を合計し、大きい順に上位を選びます。

群を同じ重みで扱うので、検体の多い群に引っぱられません。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` (検体ごと・タクソンごとのリード数) です。
- 相対存在量は、希薄化の前のリード数から計算しています。割合にするので、検体ごとのリード数の違いはそろいます。
- 深さの下限に届かなかった検体は、平均にも、上位の選び方にも入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。図の名前と元の分類の対応は `../00_info/taxa_names_<階級>.csv` です。

## CSV の列

**`07_stacked-group_<階級>.values.csv`** (1 行が 1 群)

| 列 | 中身 |
| --- | --- |
| `group` | 群の名前 |
| タクソンの名前の列 (上位の数だけ) | そのタクソンの、群の平均の相対存在量 (%)。左が 1 位です |
| `Others` | 上位に入らなかったタクソンの合計 (%) |
| `n` | その群の検体の数 |

**`07_stacked-sample_<階級>.values.csv`** (1 行が 1 検体。図の左から順)

| 列 | 中身 |
| --- | --- |
| `sample` | 検体の名前 |
| タクソンの名前の列 (上位の数だけ) | そのタクソンの相対存在量 (%) |
| `Others` | 上位に入らなかったタクソンの合計 (%) |
| `group` | 群の名前 |
| `excluded` | `True` なら、解析から外れた検体 (値は空です) |

## 注意

- 相対存在量は割合です。あるタクソンが増えると、ほかのタクソンは量が変わらなくても割合が下がります。割合の増減は、菌の量そのものの増減とは限りません。
- 上位に入らなかったタクソンも含めた全部の値は、`../10_taxon-bar/csv/` にあります。
