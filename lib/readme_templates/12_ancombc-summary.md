# 12_ancombc-summary: ANCOM-BC まとめ (量の多いタクソンから)

対照群と比べて、量が増えたタクソンと減ったタクソンを示した図です。計算は `../11_ancombc/` と同じで、図に載せるタクソンの選び方だけが違います。こちらは、対照群でもともと多いタクソンから順に載せます。階級 (属など) ごとに 1 枚です。対照群を決めたときだけ作られます。

## 11_ancombc との違い

| | 11_ancombc | 12_ancombc-summary (この図) |
| --- | --- | --- |
| 載せるタクソン | 有意なものを、変化の大きい順に | 有意なものを、対照群で多い順に |
| 向いている見方 | 大きく変わったタクソンを知る | 主な構成の菌がどう変わったかを知る |

## 図の読み方

- **行:** タクソンです。対照群でいちばん多いタクソンが、いちばん上です。名前は右に書いてあります。
- **列:** 群です。下に、群の色の帯と名前があります。
- **対照群の列 (色の付いたマスと数字):** 対照群での、平均の相対存在量 (%) です。`<0.1` は 0.1% 未満です。色の目盛は左端のバー (Relative abundance) です。
- **ほかの群の列 (円):** 対照群と比べた結果です。
  - **円の色 (Log fold change):** 赤は対照群より増えた、青は減ったことを示し、濃いほど変化が大きいことを示します。自然対数で表した倍率で、0.69 が 2 倍、2.3 が 10 倍、−0.69 が 2 分の 1 です。
  - **円の大きさ:** q 値 (補正したあとの p 値) の 3 段階です。大きいほど q 値が小さく、`_legend.pdf` に見本があります。
  - **灰色の小さな点:** 有意でない組です。
  - **空欄:** 検定されなかった組です。
- **`n < {{min_n}}`:** 検体が {{min_n}} つに満たない群は計算に入れず、群の色の帯の中に `n < {{min_n}}` と書きます。

## 図に載せるタクソンの選び方

1. どれかの群との比較で有意だったタクソンを集めます。
2. 対照群での平均の相対存在量の多い順に並べ、上から、載せる数だけ取ります (`all` なら全部)。

有意の決め方と、検定されない組 (構造的ゼロ) については、11 と同じです。

- **有意:** q 値が 0.05 より小さく、かつ、感度解析 (0 のリード数に小さな数を足して計算し直しても結果が変わらないことの確認) を通った組です。
- **検定されない組:** ある群のすべての検体で 0 だったタクソンは、どの群との比較も検定されません。

## 値の出どころ

- 元の値は `../../../Qiime2/09_taxonomy/collapsed_table_<階級>.tsv` (検体ごと・タクソンごとのリード数) です。希薄化の前のリード数を、そのまま ANCOM-BC2 に渡しています。
- 深さの下限に届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。
- タクソンの名前の付け方は `../README.md` の「タクソンの名前」にあります。

## CSV の列

**`all.csv`** (1 行が、1 つのタクソンの、対照群と 1 つの群の比較)

| 列 | 中身 |
| --- | --- |
| `taxon` | タクソンの名前 |
| `control`・`group` | 対照群と、比べた群 |
| `n_control`・`n_group` | それぞれの群の、計算に使った検体の数 |
| `ln_fc` | Log fold change (自然対数)。正なら対照群より増えた、負なら減った |
| `log_base` | 対数の底 (`natural (ln)`) |
| `SE` | `ln_fc` の標準誤差 |
| `W` | 検定の統計量 (`ln_fc` ÷ `SE`) |
| `pvalue` | p 値 (補正の前) |
| `qvalue` | q 値 (補正のあと) |
| `diff` | `True` なら q 値が 0.05 より小さい |
| `passed_ss` | `True` なら感度解析を通った |
| `sig` | `True` なら有意 (`diff` と `passed_ss` の両方が `True`)。図の円は、この列で決めています |
| `not_tested` | `True` なら、そのタクソンのほかの群が構造的ゼロだったため、検定されなかった組 |
| `struc_zero` | `True` なら、この組のどちらかの群が構造的ゼロ |
| `zero_in_control`・`zero_in_group` | 対照群、比べた群が、それぞれ構造的ゼロかどうか |
| `method`・`ancombc_version` | 計算の方法と、R の ANCOMBC の版 |
| `pseudo` | 計算のときに 0 に足した数 (0 = 足していない) |
| `sensitivity` | 感度解析で足した数 |
| `p_adjust` | q 値の補正の方法 (BH = Benjamini–Hochberg) |
| `mdfdr` | 複数の群と比べるときの補正の方法 |
| `prv_cut` | 出現率で外す基準 (0 = 外していない) |
| `neg_lb` | 構造的ゼロの判定に、下限を使う方法を使ったか (`False` = 使っていない) |
| `seed` | 乱数の種 |

**`plotted.csv`** (図に載せたタクソンだけ): `all.csv` の結果の列に、`mean_relative_abundance_<対照群>` (対照群での平均の相対存在量 %) が付きます。

**`direction.csv`**

| 列 | 中身 |
| --- | --- |
| `scope` | `all_significant` は有意なもの全体、`plotted` は図に載せたもの |
| `taxa` | タクソンの数 |
| `increase` | 増えた組 (タクソン × 比べた群) の数 |
| `decrease` | 減った組の数 |

## 注意

- 対照群で多いタクソンから載せるので、載せる数を絞ると、減ったタクソンが主に載ります。対照群でほとんどいなかったのに増えたタクソンは、下の方か、図の外になります。増減の全体の数は `direction.csv` で確かめてください。
- 検体が少ないと、検出できる違いは限られます。有意でないことは、差が無いことの証明ではありません。
- 対照群の検体が {{min_n}} つに満たないときは、図も CSV も作られません。
