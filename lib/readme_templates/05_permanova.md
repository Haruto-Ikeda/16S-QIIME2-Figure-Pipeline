# 05_permanova: PERMANOVA と PERMDISP

群の組ごとに、菌叢が違うかどうかを検定した結果の図です。04 の PCoA で見えた群の離れ方を、数字で確かめるために使います。距離の測り方は 4 つあり、1 つにつき 1 枚です。

## この実行の設定

| 項目 | 値 |
| --- | --- |
| 検定に必要な最小の n | {{min_n}} |
| 並べ替えの回数 | {{nperm}} |
| 乱数の種 | {{perm_seed}} |
| p 値の補正 | Benjamini–Hochberg (検定ごと、距離ごとに、すべての組の中で) |
| 希薄化の深さ | {{depth}} リード |
| 検定に入った検体 | {{samples_used}} |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `05_permanova_<距離>.pdf` | 図 |
| `csv/05_permanova_<距離>.stats.csv` | 検定の結果 (群の組ごと) |

`<距離>` は `jaccard`・`bray_curtis`・`unweighted_unifrac`・`weighted_unifrac` の 4 つです。それぞれの意味は、`../04_pcoa/README.md` の「4 つの距離」にあります。

## 2 つの検定

| 検定 | 確かめていること |
| --- | --- |
| PERMANOVA | 2 つの群の中心 (菌叢の位置) が違うか |
| PERMDISP | 2 つの群の、群の中でのばらつきの大きさが違うか |

どちらも、検体の群のラベルを 999 回並べ替えて p 値を出す検定です。

## 図の読み方

- **マス:** 1 つのマスが、群の 1 組です。下の群名と左の群名の交わるところを見ます。
- **マスの色 (PERMANOVA R²):** 2 つの群の検体のあいだの違い全体のうち、群の違いで説明できる割合です。0〜1 で、1 に近い (明るい色) ほど、群がはっきり分かれています。
- **マスの中の文字:** 上が PERMANOVA の q 値、下が PERMDISP の q 値です。q 値は、補正したあとの p 値です。0.05 より小さければ有意です。
- **`q ≤ 0.001`:** 999 回の並べ替えで出せる、いちばん小さい値です。
- **灰色のマスの `n < {{min_n}}`:** 検体が {{min_n}} つに満たない群を含む組です。検定していません。
- **`not testable (min p = …)`:** 検体が少なく、どれだけ差があっても p 値が 0.05 以下になりえない組です。R² の色だけを示し、q 値は出していません。
- 星は使っていません。

## 結果の読み合わせ方

| PERMANOVA | PERMDISP | 読み方 |
| --- | --- | --- |
| 有意 | 有意でない | 群の中心が違うと読めます |
| 有意 | 有意 | 中心の違いか、ばらつきの違いか、区別できません。04 の PCoA で、群の位置と広がりを見て判断してください |
| 有意でない | どちらでも | 中心の違いは検出されませんでした |

PERMDISP が有意でないことは、ばらつきが等しいことの証明ではありません。検体が少ないと、違いがあっても検出できません。

## 値の出どころ

- 元の値は `../../../Qiime2/07_diversity/<距離>_distance_matrix.tsv` (検体どうしの距離) です。リード数を希薄化の深さにそろえたあとの距離です。
- 組ごとに、その 2 群の検体だけを取り出して検定しています。
- 深さに届かなかった検体は入りません。どの検体かは `../../../Qiime2/06_rarefaction/excluded_samples.tsv` にあります。

## CSV の列

**`stats.csv`** (1 行が、群の 1 組)

| 列 | 中身 |
| --- | --- |
| `groupA`・`groupB` | 比べた 2 つの群 |
| `n_A`・`n_B` | それぞれの群の検体の数 |
| `permanova_F` | PERMANOVA の統計量 (pseudo-F) |
| `R2` | PERMANOVA の R²。F ÷ (F + (2 群の検体の数 − 2)) で計算しています |
| `permanova_p` | PERMANOVA の p 値 (補正の前) |
| `permdisp_F`・`permdisp_p` | PERMDISP の統計量と p 値 (補正の前) |
| `min_p` | その検体数で、並べ替えから出せるいちばん小さい p 値 |
| `testable` | `True` なら検定できた組。`False` なら q 値を出していない組 |
| `reason` | 検定できなかった理由 (`n < {{min_n}}`・`min p = 0.10 > 0.05` など) |
| `permanova_q`・`permdisp_q` | 補正したあとの値。図に書いてある値です |
| `distance` | 距離の名前 |
| `permutations`・`seed` | 並べ替えの回数と、乱数の種 |
| `p_adjust` | 補正の方法 |
| `permdisp_test` | PERMDISP で、群の中心に何を使ったか (中央値) |
| `scikit_bio` | 計算に使ったライブラリ (scikit-bio) の版 |

## 注意

- 検体が少ない組では、q 値に下限があります。たとえば 3 検体と 3 検体の組では、並べ替えの通り数が少ないので、有意になりえません (`not testable`)。差が無いという意味ではありません。
- 補正は、1 つの距離の中の組どうしで行っています。4 つの距離のあいだでは補正していません。
- 乱数の種を固定しているので、同じ入力からは同じ値が出ます。
